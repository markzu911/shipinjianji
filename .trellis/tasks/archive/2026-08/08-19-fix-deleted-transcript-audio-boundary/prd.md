# 修复删除文案的音频边界

## Goal

建立适用于所有文字删除的通用声学边界不变量：完整移除被删文案的头尾残音，同时严格保留相邻未删除文案的起始和结束声音，不依赖具体文案、时间点或录音音量。

## Background

- 当前实现已增加“不可越过下一保留字符”的共享声学边界保护，用于避免裁剪吞掉下一段文案。
- 最近草稿 `data/jobs/cecce040-06bb-4710-b889-38efe3d4e180/cut-draft.json` 新增删除“自己选出来的”：语义与物理终点都停在 `6.250s`，下一段“说实话”也从 `6.250s` 开始。
- 对同一源视频和历史原始转写做只读诊断时，当前实现返回 `sharedEnd=6.250s`。`6.250s` 的多尺度 RMS 约为 `132`，因低于固定安静阈值 `500` 而提前返回；但安全走廊端点 `6.332s` 的 RMS 约为 `21`，之后约 `6.45s` 才出现明显能量上升，证明绝对安静阈值掩盖了仍可用于清除尾音的相对衰减。
- 对同一局部波形只改变增益时，`0.5x/1x/2x` 均返回 `6.250s`，`4x` 却返回约 `6.329s`；音频结构不变但边界改变，证明根因是一条通用的增益敏感规则，而非该文案的特殊时间戳。
- 归档任务 `08-17-eliminate-deleted-text-tail-protect-next-speech` 已建立共享声学边界，但其规则“fallback 已低于绝对安静阈值时保持不动”没有覆盖低底噪、低音量尾音仍继续衰减的真实情况。
- 本任务需要同时满足“删除完整”和“保留完整”，不能通过固定毫秒扩张或跨越下一字符走廊来换取去除尾音。

## Confirmed Facts

- 根因位于后端 `refine_shared_character_boundary` 的安静 fallback 提前返回，不是前端显示状态或 FFmpeg 生成阶段二次吸附。
- 前端预览、草稿保存和生成已经消费持久化的 `textRanges[].start/end`；修正共享边界所有者即可让各消费者获得同一结果。
- 现有字符中心走廊、方向约束、相对改善阈值和短保留字符保护可以继续限制候选，不需要恢复完整 ASR token 扩张。
- AI 建议初始化和草稿 PUT 已共同调用后端共享边界所有者；预览和生成消费保存结果，因此通用修复必须落在该所有者并对两个入口做契约测试。

## Requirements

- R1：删除文案的最终媒体范围必须覆盖该文案的完整发音，包括尾音。
- R2：删除结束边界不得进入下一段未删除文案的发音区间。
- R3：前端预览、草稿保存与最终生成必须使用一致的安全边界。
- R4：不得放宽现有手动时间轴删除的语义，也不得迁移或重写既有草稿文件。
- R5：修复应覆盖相邻文案时间边界紧密、存在安全静音间隔和模型时间戳粗粒度三类情况。
- R6：共享边界不得仅因 fallback 低于固定 RMS 阈值就停止；当同一受限走廊中存在显著更低的方向候选时，仍应使用相对能量改善完成尾音裁剪。
- R7：均匀静音、均匀低音量、无方向改善、单调斜坡或下一字已起音时必须保持 fallback，不得把低音量本身误判为可扩张依据。
- R8：候选是否优于 fallback 必须以局部相对能量和形状为主；在不削波且保持波形结构的合理增益变化下，边界选择应保持在一个采样步长容差内，固定 RMS 阈值不得改变“是否继续搜索”的决策。
- R9：通用安全不变量必须同时覆盖删除起点与终点、同一 ASR token 与跨 token、单范围与相邻多范围、连续语音与真实停顿；实现不得出现针对文本、时间戳或单个草稿的分支。
- R10：所有自动文字删除入口必须复用同一候选判定和最终边界约束；任何候选非有限、反向、越过走廊或破坏保留字符核心时统一回退。

## Acceptance Criteria

- [x] AC1（R1）：删除文案后，预览与生成结果中听不到该文案残留尾音。
- [x] AC2（R2）：紧邻下一段文案时，下一段的首字和起音保持完整。
- [x] AC3（R3）：草稿 PUT 返回、公共预览、单独剪辑和统一组合使用同一最终删除范围。
- [x] AC4（R5）：有安全静音间隔时可利用该间隔完成去尾音；无可证明安全间隔时仍不得越过下一段保留发音边界。
- [x] AC5（R4）：现有手动时间轴行为与历史草稿文件保持不变。
- [x] AC6（R6）：低底噪样本中，fallback 已低于 `CUT_LOW_ENERGY_RMS_THRESHOLD` 但方向端点至少满足现有相对改善阈值时，删除终点继续后移到共享低谷。
- [x] AC7（R2、R7）：均匀静音/低音量、无改善和下一字从 fallback 立即起音的样本保持原边界；现有“得你”“给一”、单调斜坡、下一字符后静音与短保留字符测试继续通过。
- [x] AC8（真实媒体）：对 `4.871–6.250s` 的“自己选出来的”重新计算后，物理终点进入 `6.250–6.332s` 的安全走廊，清除残留尾音且不进入下一字声学核心。
- [x] AC9（R8）：同一合成边界样本在多组不削波增益下得到相同或一个 `CUT_BOUNDARY_STEP_SECONDS` 内的结果；低音量版本不再因绝对阈值提前返回。
- [x] AC10（R9、R10）：参数化矩阵覆盖起点/终点、同 token/跨 token、静音/连续语音/单调斜坡、前后保留字符、短保留字符岛和相邻多范围，并逐项断言方向、走廊、单调及保留核心不变量。
- [x] AC11（R3、R10）：AI 建议初始化与草稿 PUT 对同一语义范围、转写和 PCM 产生相同物理边界；公共预览、剪辑和组合不重新计算或裁回语义点。

## Out Of Scope

- 不改变 AI 文案选择内容、置信度或文案分词展示。
- 不扫描、迁移或手工改写 `data/jobs` 中的历史草稿。
- 不改动与音频删除边界无关的艺术字、画中画或导出功能。
- 不引入 forced-alignment 模型，不改变 ASR 服务、分词或时间戳存储格式。

## Key Decisions

- 保留现有共享声学边界架构，移除“绝对安静即提前停止”以及端点、起点补充走廊中的同类绝对阈值分叉；候选仍必须同时满足方向、走廊、相对改善和谷底形状约束。
- 将“候选相对 fallback 是否有意义”收敛为统一判定，避免端点、内部低谷或后续调用方再次各自引入绝对阈值短路。
- 删除终点继续禁止进入下一保留字符的 token 补充走廊，最大范围仍由下一字符声学中心限定。
- 真实 `data/jobs` 与历史文件只用于只读诊断；自动化测试使用合成 PCM，不把用户数据固化为 fixture。

## Risks And Deferred Items

- 波形低谷仍是声学启发式而非语言学强制对齐；无显著相对改善时继续安全回退，可能少删极弱尾音，但不能猜测性删除下一字。
- “不再出现类似错误”在本任务中落实为可执行的不变量和性质测试：不因文案、时间戳或合理录音增益改变决策，并对所有边界入口统一约束。连续语音若不存在可证明的安全声学交界，仍以保留下一字为最高优先级；在不引入强制对齐模型的前提下不能对任意人声做数学上的零残音承诺。
- 已保存草稿不会自动迁移；用户下次正常保存时按修正后的共享边界重新计算。
