# 通用文字删除声学边界设计

## Boundary Ownership

- `originalStart/originalEnd` 继续表示删除哪些文字字符。
- `start/end` 继续表示实际媒体裁剪点，由后端共享声学边界唯一生成。
- 前端预览、`/cuts`、公共预览和 `/compose` 继续消费已保存的 `start/end`，不新增二次吸附。
- retained transcript 继续只按文字语义删除，不使用物理扩张决定删字。

## Root Cause

`refine_shared_character_boundary` 在 fallback 的多尺度 RMS 不高于 `CUT_LOW_ENERGY_RMS_THRESHOLD` 时立即返回。该绝对阈值适合识别明显静音，但不能证明 fallback 已经是局部最佳交界。低底噪录音中，尾音边缘可能已经低于 `500`，随后仍从约 `132` 衰减到约 `21`；提前返回会把这段可辨识尾音留在保留媒体中。

## Generic Invariants

- Direction：删除终点只能从语义 fallback 向后，删除起点只能向前。
- Corridor：候选只能位于相邻删除/保留字符共享声学走廊，终点不得进入下一 token 补充走廊。
- Relative evidence：移动必须由局部相对能量改善或合法局部低谷证明，固定绝对阈值不能单独决定停止搜索。
- Gain stability：对不削波的统一增益变换，候选排序、方向和边界结果在一个采样步长内稳定。
- Shared ownership：AI 建议与草稿 PUT 使用同一边界函数；预览和生成只消费持久化结果。
- Safe fallback：任一不变量无法证明时返回语义 fallback，不猜测性扩张。

## Algorithm Change

1. 保留非有限 RMS 的安全回退。
2. 取消“fallback RMS 低于固定阈值就无条件返回”的规则，始终在既有方向字符走廊中建立候选。
3. 将端点和内部低谷对 fallback 的相对改善收敛到同一严格判定；方向端点还必须位于整条字符走廊的谷底，固定绝对阈值不再参与共享边界候选资格。
4. 均匀静音或均匀低音量没有相对改善，仍返回 fallback。
5. 删除起点的 token 补充走廊改用至少两个采样步长组成的相对谷底；仅当它比字符走廊候选仍显著更低时才优先，避免增益变化触发不同搜索路径。
6. 删除终点的走廊仍止于下一保留字符的声学中心，且不启用下一 token 延伸；下一段首音保护不变。
7. 在返回前统一校验候选有限、方向正确、位于走廊内且不破坏保留字符核心；失败时只回退 fallback。

## Safety Argument

- 终点只允许向后移动，起点只允许向前移动。
- 最大候选仍被相邻字符中心走廊截断，不能搜索下一保留字符说完后的静音。
- 方向端点必须同时满足相对改善和整条走廊谷底形状，不能因缩小增益后落入固定阈值而获得资格。
- 起点 token 补充走廊必须形成持续谷底且显著优于字符走廊候选，单个端点或单调斜坡不能触发扩展。
- 纯静音的 reference 与 candidate 都为零，不满足严格相对改善，保持 fallback。
- 响亮、单调或无局部改善的下一字起音不会成为合法候选。

## Compatibility

- 不改 API、草稿 schema、前端字段或历史数据格式。
- 缺少音频、`asrWords` 无效或字符映射失败时继续回退语义字符边界。
- 手动时间轴删除和自动空白范围不经过本次规则变更。

## Validation

- 新增低底噪尾音合成 PCM：fallback 已低于绝对阈值，但安全方向端点显著更低，断言终点后移且不超过下一字符声学中心。
- 新增或加强下一字立即起音样例，断言没有相对低谷时保持 fallback。
- 增加增益性质测试：对同一 PCM 结构施加多组不削波增益，内部低谷、方向端点和起点 token 补充谷底的边界结果保持稳定；缩小增益后的单调斜坡仍回退。
- 增加参数化边界矩阵：同 token/跨 token、前后方向、连续语音/静音/斜坡、单范围/相邻多范围和短保留字符岛。
- 对 AI 建议初始化与草稿 PUT 输入同一语义范围和 PCM，断言物理边界一致。
- 运行完整 `test_cut_acoustic_boundaries.py`，覆盖均匀静音、均匀响声、单调斜坡、“得你”“给一”、下一字符后静音和短保留字符。
- 运行剪辑草稿与渲染回归，确认保存、预览和生成仍共享同一物理范围。
- 对真实源视频只读计算 `4.871–6.250s` 边界，确认结果位于 `6.250–6.332s`；验证产物只能写入系统临时目录。

## Rollback

改动限定在共享声学边界判定及其回归测试。若出现保留首音回归，回滚该判定和新增测试，不改动字符语义、草稿 schema 或用户数据。
