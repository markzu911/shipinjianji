# 拆分艺术字选择页面并简化模板选择

## Goal

将艺术字的“新增/选择”和“参数设置”拆分为两个职责清晰的子页面，减少艺术字设置页的信息拥挤；同时把艺术字模板从多列说明卡片改为紧凑的下拉选择，让用户只通过模板名称和实际样式预览完成选择。

## Background

- 当前 `web/editor-art-tool.js:50-95` 的艺术字工具只有“艺术字设置”和“AI 推荐”两个页签；设置页同时承载实例列表、自定义文字新增、视频文案一键添加、详情设置和模板网格。
- 当前实例选择由 `[data-art-list]` 承载：普通艺术字逐项显示，同一 `trackId` 的视频文案艺术字聚合成一个整轨入口。模板选择位于详情字段集内，修改当前实例或整条文案轨的 `artStyle` 与共享样式。
- 当前模板网格由 `renderTemplates()` 动态生成名称、样式样例和介绍文字；说明内容高度不同，造成排列不整齐并占用较多纵向空间。
- `EditorArtTool` 只持有 tab、表单焦点和 AI 草稿等瞬时 UI 状态；艺术字、选择、预览、时间轴和生成继续由顶层 Store 与注入的 services 统一管理。本任务不得创建第二份艺术字状态或媒体运行时。
- 用户已确认模板属于详情设置：模板下拉保留在“艺术字设置”，新“选择艺术字”页只负责新增和选择艺术字实例。
- 用户已确认进入与切换规则：无选中项时进入“选择艺术字”，已有选中项时进入“艺术字设置”；在选择页新增或选择后自动进入设置页。

## Requirements

- R1：艺术字页新增“选择艺术字”子页面，与“艺术字设置”“AI 推荐”组成三个同级页签，顺序固定为“选择艺术字 / 艺术字设置 / AI 推荐”。
- R2：现有自定义文字新增、视频文案一键添加和艺术字实例/整轨选择迁入“选择艺术字”页面；普通艺术字仍逐项显示，同一视频文案轨仍只显示一个聚合入口。
- R3：“艺术字设置”页面移除实例列表、自定义文字新增和视频文案一键添加，仅保留当前已选艺术字的详情标题、空状态及原有参数字段。
- R4：艺术字模板保留在“艺术字设置”的详情字段集中，由当前卡片网格改为下拉控件；收起态与展开选项都只展示模板名称和对应艺术字样式预览，不展示适用场景或说明文案。
- R5：没有已选艺术字时，进入工具默认打开“选择艺术字”；已有选中项时默认打开“艺术字设置”。在选择页新增手动艺术字、生成视频文案艺术字或选择现有实例/整轨后，自动切换到“艺术字设置”；删除最后一个艺术字后回到“选择艺术字”。
- R6：模板变化仍使用现有模板 ID、catalog、renderer 和 Store command；普通实例只更新目标，视频文案艺术字按 `trackId` 更新整轨，且不得改变时间、源锚点或 `timingRevision`。
- R7：页签与模板下拉支持鼠标和键盘操作，具有明确的焦点、展开、选中和关闭状态；隐藏 panel 不可聚焦，模板下拉关闭后不残留可聚焦选项。
- R8：桌面与 375px 移动宽度不得出现模板文字溢出、横向滚动或控件重叠；修改不得重载基础媒体、创建 iframe 或破坏公共预览、时间轴、刷新恢复与统一生成。

## Acceptance Criteria

- [x] AC1：艺术字页显示“选择艺术字 / 艺术字设置 / AI 推荐”三个同级页签；页签与 panel 通过 `id`、`aria-controls`、`aria-labelledby` 双向关联，方向键/Home/End 可切换，隐藏 panel 不可聚焦。
- [x] AC2：“选择艺术字”页面可完成自定义文字新增、视频文案一键添加、普通实例选择和视频文案整轨选择；设置页面不再出现这些控件。
- [x] AC3：无选中项进入工具时显示选择页；已有选中项进入时显示设置页；从选择页新增或选择后自动显示对应详情，删除最后一项后自动回到选择页。
- [x] AC4：“艺术字设置”中的模板选择是单一下拉控件；触发器和每个选项只显示模板名称和真实样式预览，现有介绍段落及卡片网格不再出现。
- [x] AC5：模板下拉具备 `aria-haspopup`/`aria-expanded`/listbox 语义；Enter/Space、方向键、Home/End、Escape 和 Tab 行为可预测，点击控件外或切换页签时关闭。
- [x] AC6：选择模板后，普通实例只增加一次非 timing revision；视频文案整轨的全部 cue 使用同一模板且只增加一次非 timing revision；文字、编辑/源时间、字符 timing 和 `timingRevision` 保持不变。
- [x] AC7：新增、选择、设置、删除、AI 确认、工具切换、刷新恢复、公共预览、公共时间轴与统一生成保持现有单 Store 语义，基础 video 不写入 `src`、不调用 `load()`，运行 DOM 中 iframe 数量恒为 0。
- [x] AC8：桌面和 375px 下三个页签保持可用，选择列表和模板下拉无横向溢出、重叠或文字截断；所有交互目标至少 44px。
- [x] AC9：相关静态契约、真实浏览器艺术字工作流、完整 `tests/app/browser`、完整 pytest、全部前端 JavaScript 语法检查和 `git diff --check` 通过。

## Out of Scope

- 不新增、删除或重设计艺术字模板，不修改模板的实际预览/导出渲染样式。
- 不改变手动艺术字与视频文案艺术字的轨道分组规则。
- 不修改 AI 推荐算法、服务端接口、compose schema 或生成算法。
- 不重做艺术字详情面板的其他字段、位置预设或整体视觉主题。
- 不恢复独立艺术字页面、iframe、消息桥或第二套 Store/媒体/时间轴。
