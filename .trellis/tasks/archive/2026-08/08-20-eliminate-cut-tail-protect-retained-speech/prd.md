# 彻底消除裁剪尾音并保护下一段语音

## Goal

建立一条适用于 AI 文案删除、手动文案删除和手动时间轴删除的统一声学边界契约：完整清除被删文案的可辨识头音、尾音和音节，同时不删除或削弱前后未选中文案的起音与完整发音。

## Background

- 用户提供的成片 `C:\Users\jiadi\Downloads\飞书20260728-152857-当前预览版 (5).mp4` 的 SHA256 为 `092BA36E026F6B9291F690526E0E2575406E555B2CFD1A36A7669B46B1776A35`，与 `data/history/history-049a03bc6dac45c782e82181bd002b1c/video.mp4` 完全一致。
- 该成片约 `146.700s`，源视频约 `184.000s`。PCM 指纹比对确认成片约 `23.0s` 处是源视频重复文案删除后的拼接点。
- 源 ASR 将相邻的“得你”合并在 `36.760-37.480s` 的同一原始 token 内。当前实现均分字符时间，把“得/你”先验交界放在 `37.120s`。
- `refine_shared_character_boundary()` 把该删除终点移到 `37.190s`，但该点多尺度 RMS 仍约为 `3136`，处于连续发音中；当前相对低谷评分仍可接受这个高能量局部最小值，导致被删字尾音进入右侧保留片段。
- 固定 `fa-zh v2.0.4` 的完整句段实测把被删“得”定位为约 `37.570-37.810s`，下一保留“你”定位为约 `39.850-40.010s`，中间与既有 `37.800-39.680s` quiet range 一致。DashScope 粗 token 不仅缺少 token 内字界，还会在重复文案和长静音处压缩实际时间，因此不能充当逐字符时间硬包络。
- AI 删除和手动文案删除共用这套边界，因而两者都可复现。`timelineRanges` 则被明确保持为用户拖拽的精确时间，完全绕过声学吸附，所以时间轴手动删除也会在终点偏早时留下尾音。
- FFmpeg 生成链使用解码后的 `atrim` 和 `8ms` 淡入/淡出；AAC 输出帧约 `10.67ms`。证据表明根因是物理恢复点仍位于被删发音中，不是编码器把已删音频重新带回。
- 相关旧任务已建立“保留文字不可穿越”和“增益无关的相对低谷”契约，但明确把强制对齐和手动时间轴吸附排除在外。本任务要替换这两个已知限制，不再调整单一 RMS 阈值。

## Requirements

- R1：AI 文案删除、用户点选/恢复文案、手动时间轴删除必须在后端消费同一个权威声学边界解析器；前端不得另行重算媒体边界。
- R2：继续分离语义删除范围与物理媒体范围。语义范围决定哪些文字进入删除/恢复状态；物理范围由声学解析器唯一生成，决定预览和 FFmpeg 真实拼接点。
- R3：原始 ASR token 同时覆盖被删字和保留字，或纯波形走廊没有可证明的安全低谷时，必须使用模型级字符/音素强制对齐或等价语言学证据，不得继续使用 token 内等分时间作为最终物理边界。
- R3a：强制对齐必须使用完整 ASR 句段及有限上下文和完整已知文本；短窗局部对齐不得决定边界。`asrWords` 只用于文本顺序映射和偏差诊断，不得要求每个对齐字符落在粗 token 时间内。
- R4：对于“左侧删除、右侧保留”，最终终点必须覆盖被删字的完整发音，且不得晚于右侧保留字的可靠起音保护点；左侧保留、右侧删除时对称保护前一字完整尾音。
- R5：高能量点不得仅因“比 fallback 低”就被接受。候选必须同时满足方向、保留起音硬边界、局部谷底/过零点和对齐结构有效性；模型提供置信度时还必须达到准入要求。距离惩罚不得压过“完整删除尾音”的方向性要求。
- R6：手动时间轴范围经用户二次确认后，若起点或终点落在识别语音附近，默认吸附到同一安全声学边界；完全位于无语音区域的任意时间范围保持用户精确选择。
- R7：时间轴吸附后的最终范围必须在二次确认、公共预览和生成前可见；草稿 PUT 响应、撤销/重做、单独剪辑和统一合成必须消费同一组已持久化物理范围。
- R8：对齐或音频分析失败时，不得使用固定毫秒扩张、整个相邻 token 删除或跨过保留起音的猜测性边界。失败状态必须可诊断，并以保护未删语音为硬退化不变量。
- R9：新的字符/音素对齐结果必须可缓存、可重用，同一源媒体的多次选择、草稿保存和生成不得重复运行全量对齐；不得在撤销或轻量拖动热路径中同步阻塞界面。
- R10：新字段和对齐缓存必须向后兼容。不主动扫描、迁移或改写既有 `data/jobs` 与 `data/history`；旧任务缺少对齐数据时按明确的安全降级路径处理。
- R11：不改变当前文案内容、分词、删除/恢复状态和无语音删除语义；声学对齐只提供媒体拼接边界证据。
- R12：实现必须提供通用边界诊断数据，至少包含边界来源、原始 fallback、最终点、方向、对齐结构校验、模型实际提供的置信度、保留起音硬边界和降级原因，便于后续定位任意文案的同类问题；模型不提供置信度时不得伪造。
- R13：默认启用本地对齐前必须固定并验证 Windows/Mac 依赖组合、模型 revision 与校验和；模型按需加载和缓存，普通启动不承担冷启动推理成本，运行时不可用时必须显式诊断安全降级。

- [ ] AC1（R3-R5，真实媒体）：对本次源视频的“得你”共 token 边界重新生成，成片中听不到被删“得”的可辨识尾音，二次 ASR 不返回被删字，且下一保留“你”的波形/识别结果完整。自动化 gate 已证明 `37.810s` 满足 ASR/PCM 条件，人耳盲听仍须在最终验收执行。
- [ ] AC2（R1-R5）：`words=觉得/你`、`asrWords=得你` 和 `words=一起/给/一起/给`、`asrWords=一起/给一/起给` 都由共享边界删除完整的已选字，不覆盖下一保留字的可靠起音。
- [ ] AC3（R1、R6-R7）：对同一语音边界，AI 建议、手动文案删除和手动时间轴删除返回同一物理拼接点；时间轴确认后显示的范围与最终成片一致。
- [ ] AC4（R6）：完全落在无语音区域的手动时间轴范围仍保持用户选择的精确起止；仅在端点靠近识别语音边界时执行安全吸附。
- [ ] AC5（R2、R7）：草稿 PUT 返回的语义/物理范围、公共预览、撤销/重做、`/cuts`、`/compose` 和 retained transcript 全部一致；生成阶段不再二次吸附。
- [ ] AC6（R4-R5、R8）：高能量局部谷、单调衰减、均匀低能和跨 token 候选都有回归；没有可靠证据时绝不用固定补偿吞掉下一字。
- [ ] AC7（R5）：同一边界在多组非削波整体增益下保持决策稳定；录音音量不会使高能量点突然变成安全交界。
- [ ] AC8（R8-R10、R12）：对齐或解码失败有可断言的安全回退与诊断原因；旧 transcript/草稿可加载，未主动改写现有 jobs/history。
- [ ] AC9（R9）：同一源媒体首次对齐后可缓存复用；连续修改删除选择、撤销和重做不重复执行全量模型推理。
- [ ] AC10（R1-R12）：定向声学、草稿、真实 FFmpeg 剪辑、前端契约和真实浏览器回归全部通过，随后通过全量测试与 `git diff --check`。

## Out Of Scope

- 不改变 AI 删除建议的文案判断、类型或置信度。
- 不改变原始转写文案、Jieba 展示分词、文案编辑或艺术字时间语义。
- 不通过固定 `50-100ms` 尾部扩张、整 token 删除、长淡入或音量阈值调参伪装语言学边界。
- 不主动迁移或重新生成现有历史成片；真实素材仅作本地验证，不纳入仓库 fixture。

## Key Decisions

- 用户已确认：手动时间轴删除在语音附近默认吸附到安全声学边界，接受最终起止相对鼠标位置发生小幅变化，但预览必须显示真实结果。
- 模型原始 token 和均分字符时间只是语义映射先验，不再充当连续语音中的最终媒体拼接证据。
- 最终边界必须由后端一次决策、持久化并被所有消费者复用；不接受只修预览或只修生成。
- 保留语音起音点是不可穿越的硬边界；去尾音要在该保护内由更精确的对齐证据完成，不通过降低保护级别实现。
- 第一实现候选采用固定 revision 的本地 `FunASR fa-zh` 已知文本字符对齐；只有真实样片准入通过才接入产品。已缓存的 `faster-whisper tiny` 实测存在低置信度长跨度错配和多字符 token，不能承担权威边界。
- 自动化真实样片 gate 已通过固定 `fa-zh v2.0.4`；对齐最小单位改为完整句段，短窗和逐字符 DashScope token 时间包络均被禁止。文字删除物理终点使用被删字符可靠尾点 `37.810s`，不借机吞掉后续 quiet range；quiet 是否删除继续由现有无语音语义决定。

## Risks And Deferred Items

- 连续协同发音中可能没有真正静音，必须依赖字符/音素对齐而不是 VAD 或 RMS 单独决策。Windows 隔离实测本地环境约 `1.266GB`、峰值 RSS 约 `997MB`、模型冷加载约 `4.2-7.5s`、热推理约 `0.05-0.18s/句段`；Mac 安装/打包 gate 仍须通过才可发布，失败需返回设计阶段，不以旧算法冒充成功。
- 若素材中前后音素实际存在声学重叠，任何不做语音源分离的方法都无法给出数学上的零损失保证；验收以不存在可辨识被删音节且保留字完整为标准。
