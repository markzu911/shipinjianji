# 消除文字删除后的残音并保护相邻语音

## Goal

建立一条通用的文字裁剪声学边界契约：删除选中文案后，成片不再残留被删内容的头音、尾音或可辨识音节，同时完整保留下一个和上一个未删除字符的音频。

## Background

- 用户提供的成片 `C:\Users\jiadi\Downloads\飞书20260728-152857-当前预览版 (3).mp4` 时长约 `139.000s`，对应历史 `history-5e9a2e3345934233b7a5a9cc56d6ac33` 和源任务 `cd541254-a931-4ecc-ba86-f7ff620a56b2`。
- 该任务的第一处文字语义删除范围为 `28.454-29.171s`，目标是去除第一遍“一起给”并保留后一遍“一起给你”。成片二次 ASR 却识别为“所有人一一起给你”，证明被删内容仍有一个可辨识的“一”留在拼接点。
- 另一边界 `33.160-37.120s` 在 `37.120s` 的局部 RMS 约为 `5588`，而 `37.335s` 附近约为 `707`、`37.840s` 附近约为 `14`。现有均分字符边界会停在持续发声内部；直接向后寻找低谷又可能进入下一保留字符。
- 前置任务已经确立双层契约：`segments[].asrWords` 是原始声学参考但不是不可拆分删除单位；文字语义使用自然分词/字符单元；自动删除不得扩大到完整原始 ASR token；保留文字优先于盲目尾部延长。
- 当前根因不是删除语义错误，而是自然词内按字符均分得到的时间只能作为先验估计，不能充当真实声学交界。现有 `snap_delete_ranges_to_samples` 又把该估计同时当作硬保护上限，因此无法从持续语音中移到真正的相邻字符交界。

## Requirements

- R1：`originalStart/originalEnd` 继续只表示用户删除了哪些字符；不得扩大到整个 `asrWords` token，也不得改变前置任务的字符级删除语义。
- R2：文字删除的物理起点和终点必须从同一套“相邻字符共享声学边界”生成。删除字符的终点与下一保留字符的起点是同一个值；删除字符的起点与上一保留字符的终点同理，禁止两个消费者独立移动边界。
- R3：声学边界细化必须在原始 `asrWords` 和字符顺序限定的局部走廊内进行，综合短窗能量低谷、相对能量改善和距字符时间先验的偏移；不得使用固定毫秒尾部扩张。
- R4：边界结果必须保持单调，并为相邻字符保留有效声学核心；候选低谷若落在合法走廊之外或证据无效，必须回退到现有字符先验，不得越过相邻保留字符。
- R5：存在真实停顿时仍可吸附到停顿低谷；连续发声且删除/保留交界落在同一原始 ASR token 内时，可以在 token 内细化，但不能把该 token 作为整体删除。
- R6：AI 建议初始化、草稿 PUT 对齐、公共预览、单独剪辑和统一组合生成必须消费同一组已保存的物理边界；生成阶段不得再次独立吸附。
- R7：retained transcript、文案删除态和撤销/恢复仍只使用字符语义范围，媒体裁剪只使用细化后的物理范围，二者不得互相覆盖所有权。
- R8：音频解码失败、缺少 `asrWords`、文本无法与原始 token 对齐或候选置信度不足时，安全回退到字符级语义边界；不得恢复向完整 ASR token 扩展的旧行为。
- R9：本任务不扫描、迁移或覆盖现有 `data/jobs` 和 `data/history`。附件及其对应源文件只用于只读分析和验收，验证产物写入临时目录。
- R10：实现必须与当前未提交的字符级删除安全和段落播放改动协作，不得回退或覆盖这些变更。
- R11：连续相邻的已删文字在列表中合并为一个展示段落；展示段可以聚合多个内部 `rangeKeys`，恢复时一次恢复该段包含的全部文字范围。字符级语义、物理声学边界和独立空白项不得因展示合并而改变。

## Acceptance Criteria

- [ ] AC1（R1、R2）：`words=一起/给/一起/给`、`asrWords=一起/给一/起给` 时，删除第一遍“一起给”使用两个共享声学交界；保留结果只有后一遍“一起给”，不出现额外“一”，也不丢后一遍首字“一”。
- [ ] AC2（R1、R2）：`words=觉得/你`、`asrWords=觉/得你` 时，删除“觉得”不留下“得”的残音，同时“你”的起音和主体保持在保留区间内。
- [ ] AC3（R3、R4、R5）：构造不等长字符发声和局部低谷样本时，边界可从机械均分点移到局部声学交界；无合法证据时结果保持单调且不穿越相邻字符保护核心。
- [ ] AC4（R6、R7）：草稿 PUT 返回的 `start/end` 与预览、剪辑、组合生成实际使用值一致，`originalStart/originalEnd` 保持字符语义，retained transcript 只删除选中文字。
- [ ] AC5（R8）：缺少音频、缺少 `asrWords`、跨层文本不一致和解码失败均安全回退，已有历史 transcript/草稿仍可加载、保存和生成。
- [ ] AC6（R9）：不修改真实用户数据；所有真实媒体分析和临时重切结果位于系统临时目录。
- [ ] AC7（真实媒体）：用附件对应源视频和现有草稿重切后，拼接点不再产生“所有人一一起给”或其他被删内容的可辨识残片；二次 ASR 文本与预期保留文案一致，人工试听确认下一保留字符完整。
- [ ] AC8（回归）：前置任务关于 `给一`、`得你`、短保留字符、空白范围保护、草稿幂等和生成一致性的测试继续通过。
- [ ] AC9（R11）：同一文案段内连续已删 token 即使来自不同 `rangeKey` 也只渲染为一行，文字顺序和完整内容不变；中间存在保留文字时仍分组，点击恢复会删除该展示段聚合的全部 `rangeKeys`，空白建议继续作为独立行。

## Out Of Scope

- 不改变 AI 对“哪些文案应该删除”的判断、建议类型或置信度。
- 不把原始 ASR token 恢复为删除最小单位，不改变手动时间轴精确删除的现有语义。
- 不引入或下载新的本地 forced-alignment 模型；本次先使用现有 ASR 声学参考与源音频完成受约束边界细化。
- 不自动修复或覆盖已经生成的历史成片。

## Key Decisions

- 采用“共享边界”而不是“尾部补偿”：先确定删除字符与保留字符之间唯一的声学交界，再由两侧共同使用，避免一侧消尾音、另一侧又被误删。
- `asrWords` 只限定声学搜索走廊和字符顺序；删除语义仍由自然分词/字符单元决定。
- 优先在现有依赖内实现多尺度能量细化并用真实媒体验收，避免重新引入体积大、部署复杂的本地模型。若真实连续语音无法提供可靠声学交界，forced alignment 作为后续独立能力评估，不以扩大删除范围冒险代替。

## Risks And Deferred Items

- 纯波形低谷无法对所有连续语音提供语言学意义上的绝对字符边界；本任务通过原始 token 走廊、相邻字符核心、单调约束和真实媒体回归降低风险，但不会宣称获得模型级强制对齐精度。
- 旧 transcript 缺少 `asrWords` 时只能安全回退，可能继续少删少量残音，但不得误删保留文案。
- 专用中文 forced-alignment 模型涉及新依赖、模型下载、冷启动和部署策略，若本次真实媒体验收无法同时满足无残音与保留首字，应另建任务评估，不在本任务中静默引入。
