# 统一全应用 UI 密度

## Goal

参考用户提供的紧凑型文案列表界面，统一应用内操作界面的视觉密度，让同一屏能够容纳更多编辑内容；视频预览区域、预览画面比例和预览坐标系统保持不变，时间轴只做轻度缩小。

## Background

应用现有页面和编辑工具的字号、控件高度、间距与面板密度不一致。此前局部使用过紧凑样式，但不能通过根节点 `zoom`、整体 `transform: scale()` 或缩放工作区来统一，否则会连带改变视频预览尺寸，并可能破坏艺术字、画中画及鼠标指针的坐标映射。

当前公共剪辑时间轴基础轨道高度为 92px，显示效果轨时为 122px；视频预览舞台与时间轴使用独立布局，可分别调整。

## Requirements

### R1. 统一紧凑视觉密度

- 应用内导航、面板、列表、表单、按钮、状态卡片和辅助文案采用一致的紧凑密度规则。
- 优先压缩无效留白、垂直间距、控件外观尺寸和辅助文字，不使用全页面统一缩放。
- 关键正文仍须清晰可读，不能因压缩产生文字裁切、重叠或不可辨识。

### R2. 预览区域保持不变

- 视频预览面板、视频舞台、画布、播放器和预览内容的可见尺寸不得因本任务缩小。
- 视频宽高比、`object-fit`、艺术字/画中画覆盖层坐标及鼠标点击映射不得改变。
- 剪辑、艺术字和画中画页面共享预览时，必须保持一致的预览几何尺寸。

### R3. 时间轴仅轻度缩小

- 主剪辑时间轴、艺术字轨道和画中画轨道采用一致的轻度紧凑比例，不按参考图进行 50% 缩放。
- 刻度、文案轨、缩略图轨、效果轨和轨道间距应同步调整，不能只压缩外壳导致内容溢出。
- 时间轴宽度、时间映射、播放头位置、点击定位、拖拽、分割和删除边界语义保持不变。
- 分割、拖拽等关键交互的有效命中区域不得因视觉压缩而难以操作。

### R4. 响应式与页面完整性

- 桌面端优先按照参考图形成高信息密度布局，同时保持左右区域铺满现有工作区。
- 窄屏下不得出现因紧凑规则导致的横向溢出、遮挡或无法滚动。
- 设置页、字体管理页、艺术字模板库和主编辑器使用同一套密度基准，但可根据页面内容保留必要的最小尺寸。

### R5. 可维护性

- 使用语义化密度变量或限定作用域的组件规则实现，避免散落的重复魔法数。
- 不得使用会影响预览坐标或媒体尺寸的全局 `zoom`/`transform`。
- 更新所有受影响的前端资源缓存版本，并补充关键布局契约测试和浏览器回归测试。

## Acceptance Criteria

- [x] AC1. 主编辑器、艺术字、画中画、设置、字体管理和艺术字模板库的操作 UI 呈现统一的紧凑密度。
- [x] AC2. 与修改前对比，视频预览区域的外部尺寸、视频内容尺寸和宽高比均不变。
- [x] AC3. 艺术字和画中画预览覆盖层的位置、大小及鼠标点击/拖拽坐标无偏移。
- [x] AC4. 主时间轴和附加轨道只做轻度缩小，轨道内容完整，无裁切、重叠或前置空白回归。
- [x] AC5. 时间轴点击定位、播放头、滚动、分割、选择、删除、恢复、撤销和重做行为保持正确。
- [x] AC6. 参考图中的文案列表、圆形选择控件、播放按钮及删除状态单元格在统一密度下保持圆形、不扭曲且可点击。
- [x] AC7. 关键文字不被截断，表单、下拉框和按钮状态清晰，键盘焦点可见。
- [x] AC8. 桌面宽屏布局铺满现有可用区域；窄屏布局无非预期横向滚动或功能遮挡。
- [x] AC9. 前端契约测试和核心编辑浏览器工作流通过，且缓存版本已更新。

## Out of Scope

- 修改视频预览内容比例、裁剪方式或导出分辨率。
- 改变时间轴的时间映射、缩放算法、分割语义或音视频裁剪边界。
- 重做配色、品牌风格或业务流程。

## Confirmed Decision

- 已确认：时间轴轨道视觉高度统一缩小约 15%，预览区域保持不变，关键操作命中区继续保持易操作。
- 已确认：顶层画中画设置面板最终从 `zoom: 0.55` 调整为 `zoom: 0.6`，即在上一版基础上约再放大 9%；公共预览和时间轴几何保持不变。
- 已确认：顶层画中画设置面板使用适合小字号中文 UI 的跨平台字体栈，正文与辅助文字权重为 500、标题与强调文字为 700；只改善文字清晰度，不改变面板、预览或时间轴几何。
- 已确认：文字剪辑列表保留紧凑行和 22px 圆形控件，但正文/时间/状态/空白说明分别提高到 10/9/7/9/8px 下限；画中画面板在 0.6 缩放前使用 small/time 15px、普通状态与控件 16px、主要选项 17px 下限，并覆盖生成素材卡。允许内容行按需自然增高，禁止裁切、重叠和横向溢出。
- 已确认：PiP 文案片段的时间列扩大为 64px，与正文保留 12px 逻辑间距；`MM:SS.d` 时间必须完整显示，正文继续单行省略，字号、zoom、radio、预览和时间轴保持不变。
