# 防止重复文案声学边界错切

## Goal

修复相邻重复文案在声学强制对齐中发生语义错位后仍被当作权威切点的问题，使 AI 文案删除、手动文案删除和手动时间轴删除都能完整移除被选语音，同时保留下一次重复表达的完整起音和正文；并修复物理声学扩展污染文字展示边界后产生的“人”“你身”等孤立行。

## Requirements

- R1：声学对齐必须区分“句段结构有效”和“当前删除/保留转场边界可信”。`validation.valid` 只能允许字符时间进入候选集，不能单独授权物理切点。
- R2：共享边界解析器必须识别删除侧与保留侧相邻的重复或重叠文案实例，包括完整短语重复、局部后缀/前缀重复和连续相同字符；检测依据是规范化可发声字符及删除状态，不依赖建议类型或某一个视频的固定文案。
- R3：重复实例存在语义歧义时，forced candidate 必须获得转场局部 PCM 证据后才能成为最终边界。解析器应在语义 fallback 与 forced candidate 之间的有界方向走廊内寻找持续、相对低能且增益无关的谷底，并把谷底后的保留起音作为不可穿越限制。
- R4：删除终点只能从语义 fallback 向后移动，删除起点只能向前移动。任何候选都不得越过已确认的保留语音核心；没有足够证据时安全回退，不用固定毫秒扩张、整 token 删除或直接信任歧义 forced candidate。
- R5：非重复且已有真实验证的边界继续使用现有 forced alignment 主路径。不得用全局 `coarseTokenMaxBoundaryDeviationSeconds` 阈值使“得/你”、长静音或合法逃出粗 token 的边界退化。
- R6：AI 建议、手动点选文案和手动时间轴删除必须复用同一个转场可信度判定与边界解析函数；草稿保存后持久化同一物理范围，预览、`/cuts`、`/compose` 和 FFmpeg 不得二次重算。
- R7：继续保持语义与物理范围分离。`originalStart/originalEnd` 决定删除哪些文字或用户确认的时间意图，`start/end` 表示经过可信边界解析后的媒体切点；修复不得改变文案内容、删除状态或 retained transcript 的语义选择。
- R8：边界诊断必须新增可断言的可信度信息，至少包含结构有效性、重复歧义原因/跨度、PCM 佐证结果、forced candidate、最终边界、保留起音限制和回退原因；旧 sidecar、草稿和历史任务继续兼容，不主动迁移。
- R9：重复歧义检测和 PCM 佐证必须复用已解码音频与现有 boundary cache，不新增模型推理，不在生成阶段增加声学对齐，也不引入新的运行依赖。
- R10：回归必须同时证明“被删语音不存在”和“下一段保留语音未受损”，并覆盖结构合法的错位对齐、合法大偏差对齐、没有谷底的安全降级、手动时间轴、草稿 revision 和统一合成。
- R11：文字剪辑列表的删除/恢复状态和 suggestion 展示边界必须只由语义 `originalStart/originalEnd` 投影；声学扩展后的物理 `start/end`、`adjacentSilence*` 和 `noSpeechRanges` 不得改变文字分组、样式或把未选字符拆成孤立行。
- R12：连续、同状态且同语义 presentation 的保留字符必须合并为正常可编辑行。修复只改变展示投影，不得改变草稿持久化、预览跳过或最终 FFmpeg 消费的物理范围。
- R13：units 列表中物理相邻、且分别为相邻 transcript segment 最后一字/第一字的转场必须进入同一个共享 resolver。两段 forced 结构均有效且不重叠时使用删除侧 forced 边界并以保留侧 forced 边界为硬限；forced 缺失或跨段 overlap 时，只能在语义边界与保留侧安全界限之间用同一 sustained-valley PCM 逻辑解析。无谷底或保留语音立即起音时回退语义边界，禁止固定毫秒扩张。

## Out Of Scope

- 不更换 DashScope 转写或 `FunASR fa-zh` 模型，不重新训练模型，也不新增第二套在线 ASR 作为生产时硬依赖。
- 不用全局粗偏差阈值、固定 `50-150ms` 补偿、整 token 删除、长淡入或音量阈值调参掩盖重复实例错位。
- 不改变重复文案检测/建议的产品判断，不改变文案编辑、艺术字、画中画或时间轴交互。
- 不主动重写历史 jobs/history；用户真实媒体只作本地只读验收，不提交仓库。

## Key Decisions

- 可信度按“删除/保留状态转换”计算，而不是把整个 forced-alignment 句段简单判成全可信或全不可信。
- 粗 ASR 时间只参与局部歧义诊断和走廊约束，不作为全局否决条件；这是保护上一轮“得/你”合法边界的必要条件。
- 重复歧义边界采用“语义 fallback + forced candidate + 持续 PCM 谷底”的三方佐证。没有佐证时优先保护下一段，不把结构合法等同于语义正确。
- 修复落在已有共享草稿解析链，确保文案删除与手动时间轴删除不会形成两个算法或两个最终切点。
- 前端文字分组只解释语义选择；物理声学范围继续原样服务播放和生成。不得为了消除孤立行而收回正确的声学扩展或合并真实删除/恢复状态。

## Risks And Deferred Items

- 连续协同发音可能不存在可分离谷底；这类素材无法同时数学保证零残音和零损伤。本任务的安全退化顺序是先保护未删语音，并以诊断暴露未佐证边界，而不是越界猜测。
- 本次真实媒体已有可用持续谷底和独立 ASR/PCM 证据，必须通过产品完整生成链复验；人耳试听仍是最终验收的一部分。
