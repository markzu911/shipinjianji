# 消除删除文案首字残音

## Goal

让 AI 建议、用户文字删除和靠近文字边界的手动时间轴删除都能完整移除被删首字的低能起音，同时不削弱前一保留文字的尾音或正文。

## Background

- 用户附件 `C:\Users\jiadi\Downloads\飞书20260728-152857-当前预览版 (9).mp4` 与 job `c55a37df-978e-486d-9c99-e0a40c1626e7` 的最终成片 SHA256 均为 `61022B1CFD9DC129AC83F89A83B200BC32CFE1D85AD521469276DD6973839994`。
- 成片约 `19.188s` 的拼接把源片 `28.328s` 左侧保留内容直接接到 `29.789s`，语义上删除第一遍“一起给”并保留第二遍“一起给你”。
- 强制对齐把前一保留字“人”的结束放在 `28.050s`，把被删首字“一”的开始放在 `28.330s`；真实 PCM 已在约 `28.300s` 开始持续抬升。当前起点因此留下约 `28ms` 的“一”起音，8ms 淡出仍不能消除人耳可辨识残片。
- `forced_alignment_transition_boundary()` 对普通可信 delete-start 直接选择右侧被删字符 `_forcedStart`，只在候选前约 `3ms` 内吸附低振幅采样；`build_shared_acoustic_delete_boundaries()` 随后直接接受该 forced 结果，不进入更宽的 PCM 静音走廊分析。
- 该成片与上一轮标记为通过的 `fixed-full-v3.mp4` 哈希相同，说明不是新渲染回归，而是此前二次 ASR、相关性与人工验收共同漏掉了很短的低能首字起音。

## Requirements

- R1：同一段内“左保留、右删除”的 delete-start 不能把强制对齐的右字符开始时间直接视为完整声学起音；它只能作为被删首字起音的上界证据。
- R2：当上一保留字符可靠尾点与被删首字符 forced start 之间存在 PCM 可证明的持续安静走廊，最终删除起点必须落在被删起音抬升之前的低能量边界，不得保留可辨识首字残片。
- R3：最终起点不得早于上一保留字符的可靠尾点；没有足够静音、持续起音或有效 forced 证据时，不得通过固定毫秒前移猜测边界。
- R4：新判定必须保持非削波整体增益不变性，并复用现有已解码 PCM、forced boundary cache 和诊断结构，不增加模型推理或生成阶段重算。
- R5：AI 建议、用户文字删除和靠近同一文字转换的手动时间轴删除必须消费同一共享边界结果；`originalStart/originalEnd` 的文字语义保持不变。
- R6：现有 delete-end、相邻重复歧义、跨段 PCM、安全降级、无声范围、分割精确边界和保留文字 hard limit 行为不得回退。
- R7：诊断必须能区分 forced candidate 与 PCM 提前后的最终 delete-start，并记录走廊/起音佐证，避免以后只看 `boundaryTrustworthy=true` 误判已完整去头音。
- R8：真实素材验收不能只依赖全文二次 ASR；必须同时检查拼接前短窗 PCM/频谱及人工试听，因为不足一个音节的残片可能不会进入 ASR 文本。

- [x] AC4（R3、R6）：构造前一保留字立即连接被删首字、没有可证明安静走廊的回归，断言不固定前移、不越过 retained hard limit，也不把单点尖谷误当边界。

- [x] AC7（R8）：定向后端、草稿、渲染、组合和全量测试通过；真实素材证据记录源/成片时间、最终边界、短窗能量和试听结论。

## Out Of Scope

- 不改变 AI 对哪段文案提出删除建议，也不改变文案、分词或删除/恢复 UI。
- 不更换 FunASR 模型、revision 或 ASR 服务，不引入语音源分离。
- 不通过固定 `20-50ms` padding、加长全局淡入淡出或删除整个相邻 token 掩盖问题。
- 不批量迁移旧 job、草稿或历史成片；已有内容仅在正常重新保存和生成时应用修复。

## Key Decisions

- 被删首字 forced start 是语言学候选而不是低能起音硬事实；delete-start 必须再经过方向明确的 PCM 起音佐证。
- 前一保留字符 forced end 是不可穿越的 hard limit；在 hard limit 之后吸收真实静音属于安全物理扩展，不改变文字语义。
- 本次只收紧共享后端边界解析和验证，不改变 FFmpeg 的 8ms 防爆音淡入淡出。

## Risks And Deferred Items

- 连续协同发音可能没有安静走廊；这类情况继续安全保留 forced/语义边界，不能承诺完全分离重叠音素。
- 真实样片的人耳验收仍是最终门槛，PCM 与 ASR 只提供可重复的辅助证据。
